# 🚀 AdityaAI – Intelligent EDA & AutoML Studio

AdityaAI is an end-to-end **data analysis and machine learning assistant** designed for analysts and data scientists.

Upload any dataset and instantly get:
- Automated EDA
- AI-driven insights
- Dataset health checks
- Business KPIs
- Supervised AutoML (Regression & Classification)
- Clustering AutoML (KMeans, DBSCAN)
- Model diagnostics & feature importance

---

## 🔍 Key Features

### 📊 Exploratory Data Analysis
- Summary statistics
- Missing value analysis
- Smart visualizations
- Correlation matrix

### 🤖 AI Insights
- Column-level insights
- Dataset health score
- ML readiness analysis
- Recommended models

### 🚀 AutoML
- Automatic target detection
- Regression & classification
- Model leaderboard
- Confusion matrix / residual plots
- Feature importance

### 🧩 Clustering AutoML
- KMeans & DBSCAN
- Silhouette scoring
- PCA-based visualization

### 💼 Business Insights
- Domain-specific KPIs
- Actionable next steps

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Plotly

## 🎯 Vision
AdityaAI aims to become a **one-stop analytics & ML product** that bridges the gap between:
- Analysts → ML practitioners
- Raw data → business decisions
